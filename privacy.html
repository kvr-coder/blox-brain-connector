Blox Brain YouTube Connector

Privacy policy

How the connector handles YouTube reports in Codex today and how planned management features would use channel data.

Data accessed and why

Blox Brain YouTube Connector uses YouTube API Services. The channel owner authorizes read-only YouTube access through Google. The connector reads channel details to confirm the authorized channel, then reads its uploads playlist. The report includes the channel name and ID, upload count, and the titles and IDs of the requested uploads.

Google handles sign-in and consent under the Google Privacy Policy.

Local storage and retention

The connector stores its Google authorization, including a refresh token, in a local file encrypted by Windows for the current Windows user. It uses that authorization to make requests to Google. The local file remains on the device until it is removed. The connector reads channel and upload details on demand and returns them directly to Codex, without keeping a separate inventory on disk.

Processing in Codex

When the owner requests a report, the connector passes the channel and upload details to OpenAI’s Codex so it can answer the request. Codex may retain those results in the conversation according to the applicable OpenAI policies and workspace settings. The OpenAI Privacy Policy and data controls describe how to manage that data.

The connector uses Google data to provide the requested channel report. The Google API Services User Data Policy, including its Limited Use requirements, sets limits on how information received from Google APIs may be used and shared.

Planned management features

With separate approval from the owner, the planned tools would handle channel profile details, video titles and descriptions, playlist details, visibility settings, and scheduled publication times. The connector would send the owner’s requested changes to YouTube for the selected channel.

For private uploads, the planned connector would read the video file the owner selects and send it from the local device to YouTube. Codex would process the requested settings and receive the upload or publishing result, such as the video ID and status. The planned design keeps Google authorization on the device using encrypted local storage.

Revoke access and remove saved data

Remove the connector in your Google Account connections to revoke its access. To remove the saved authorization from your device, delete the local encrypted authorization file. Manage or delete any conversation containing results separately in Codex.

Website and contact

This information site is hosted by GitHub Pages. GitHub logs visitor IP addresses for security as described in the GitHub Privacy Statement.

For privacy questions, contact the maintainer through the public issue tracker. Keep account details, authorization files, and private channel information out of public posts.
